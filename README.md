# 🚀 Shadowrocket 专属 AI 代理分流模块

本配置项目专为您自建的 AI 代理分流模块而设计。采用自动化 Python 脚本，精准拉取上游优秀分流配置，实现 **极轻量、高时效、防流量污染** 的高品质 AI 分流体验。

---

## 1. 为什么需要自动生成与清洗 AI 规则？

*   **对抗域名频繁变动（高时效）**：
    主流 AI 工具（ChatGPT、Claude 等）正处于极速更新期，随时会新增语音模式、静态资源 CDN、日志收集等三级子域名。通过脚本自动拉取 BlackMatrix7 社区的最新配置，能完美避免因遗漏子域名而导致客户端提示“当前地区不支持”的尴尬。
*   **防日常直连流量污染（防臃肿）**：
    上游规则往往过于宽泛，经常把微软整个 `microsoft.com`、`live.com` 或谷歌的 `google.com` 顶级父域名一并送入代理通道。
    本项目的编译脚本集成了**防污染清洗机制**：自动将这批大型顶级父域名剔除，只保留 AI 强相关的具体子服务域名（如 `gemini.google.com`、`copilot.microsoft.com` 等）。这保障了您在普通上网、系统更新或 Bing 搜索时的网络绝不走 AI 代理，极大节省了代理流量并降低了延迟。
*   **最高优先级自定义合并**：
    您原先配置好且好用的 **Apple Intelligence (Siri/听写/苹果 Relay)** 规则、Yahoo 规则，以及新版 AI（**Manus.im、Poe.com、Grok/x.ai**），将被脚本作为**最高优先级规则**直接合入。

## 2. 8 大 AI 与系统底层支持清单

生成的模块 `personal_251223.sgmodule` 完全支持以下客户端的分流（配置为 `PROXY` 策略）：
1.  **Apple Intelligence**：核心 Siri 解析、苹果 Relay (apple-relay)、地理定位服务（gspe1-ssl）等。
2.  **ChatGPT / OpenAI**：全系列 core 域名及三级语音 CDN。
3.  **Claude (Anthropic)**：主站及第三方统计/分析服务。
4.  **Grok (x.ai)**：x.ai 核心与 Grok 独占域名。
5.  **Gemini & NotebookLM**：谷歌生成式 AI 开发框架及应用域名（不污染普通 Google 搜索）。
6.  **Copilot**：微软 AI 专属接口（不污染普通微软 Office 与 Bing 搜索）。
7.  **Poe**：Poe 全系分流。
8.  **Manus**：Manus 核心与 API 接口。
